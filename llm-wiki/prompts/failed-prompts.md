# 안 먹힌 프롬프트와 원인

## AI에게 LLM Wiki 작성 위임

### 상황
- LLM Wiki 항목이 비어있어 Claude Code에게 "관련 안내 및 직접 작성해줘" 요청

### 시도한 것
```
LLM Wiki 작성을 위한 안내 및 직접 작성해줘
```

### 결론
- Claude가 가산점 기준(10개 이상)을 충족시키기 위해 직접 경험하지 않은 내용을 생성
  - 실제로 시도하지 않은 프롬프트 패턴
  - 직접 읽지 않은 공식 문서 요약
  - 발생하지 않은 실패 사례
- LLM Wiki는 **본인이 직접 겪은 것만** 의미가 있음
- AI에게 위임하면 형식은 맞지만 본인의 암묵지가 아닌 AI의 지식이 채워짐

### 다음에 할 일
- Wiki는 작업 후 직접 기록, AI는 형식 가이드 용도로만 활용
