# WBS — AI 운동 코칭 앱

> 작성: AI Agent 자동 생성 / 본인 검토 완료 (2026-05-18)

## 1. 사용자 영역

### 1.1 온보딩
- 1.1.1 첫 실행 설정 화면 (목표, 운동 경험 레벨 입력) (1d)

### 1.2 홈 화면
- 1.2.1 오늘의 운동 카드 (AI 제안 루틴 표시) (1d)
- 1.2.2 하단 네비게이션 (홈 / 기록 / 채팅 / 통계) (1d)

## 2. AI 코칭 영역

### 2.1 AI 대화 인터페이스
- 2.1.1 채팅 UI (말풍선, 입력창, 전송 버튼) (2d)
- 2.1.2 Claude API 연동 (HTTP 클라이언트, 응답 파싱) (2d)
- 2.1.3 컨텍스트 관리 (히스토리 요약 → 시스템 프롬프트 주입) (2d)

### 2.2 운동 계획 생성
- 2.2.1 AI 응답에서 루틴 파싱 로직 (1d)
- 2.2.2 파싱된 루틴 카드 UI 표시 (1d)

## 3. 운동 기록 영역

### 3.1 기록 입력
- 3.1.1 운동 종목 선택 (부위별 카테고리) (1d)
- 3.1.2 세트 / 무게 / 횟수 입력 폼 (1d)
- 3.1.3 기록 저장 및 완료 처리 (1d)

### 3.2 히스토리 조회
- 3.2.1 날짜별 운동 기록 목록 (1d)
- 3.2.2 세션별 상세 보기 (1d)

### 3.3 통계 대시보드
- 3.3.1 주간 총 볼륨 차트 (2d)
- 3.3.2 부위별 운동 빈도 시각화 (1d)

## 4. 데이터 영역

### 4.1 로컬 저장소 (SQLite)
- 4.1.1 스키마 설계 (운동 세션, 세트, 종목 테이블) (1d)
- 4.1.2 CRUD 구현 (expo-sqlite) (2d)

### 4.2 AI 컨텍스트 관리
- 4.2.1 최근 N회 히스토리 요약 로직 (2d)

## 5. 운영

### 5.1 빌드 / 배포
- 5.1.1 React Native (Expo) 프로젝트 초기 세팅 (1d)
- 5.1.2 Expo Go로 실물 기기 테스트 / EAS Build APK (1d)

### 5.2 문서 및 발표
- 5.2.1 docs/ 문서 완비 (setup, deploy, testing) (2d)
- 5.2.2 중간 발표 자료 (Marp) (1d)
