# ADR-0002: 데이터 저장 방식 선택

- 상태: Updated (expo-sqlite → sqflite, 2026-06-01)
- 날짜: 2026-05-18 / 변경: 2026-06-01
- 결정자: 원동현

## 배경

운동 기록(세션, 세트, 종목, 무게, 횟수)을 어디에 저장할지 결정.
Flutter 전환에 따라 expo-sqlite → sqflite 패키지로 변경.

## 고려한 대안

### 대안 A: sqflite (Flutter SQLite) ← **현재 선택**
- 장점: 관계형 구조에 적합, 오프라인 완전 동작, 무료, Flutter 표준
- 단점: 기기 간 동기화 불가 (Won't에서 명시적으로 제외)

### 대안 B: Firebase Firestore
- 장점: 클라우드 동기화, 실시간
- 단점: 무료 티어 한도, 네트워크 의존, 설정 복잡 → 제외

### 대안 C: Hive (NoSQL 로컬)
- 장점: 빠른 키-값 저장
- 단점: 관계형 쿼리 불가 → 운동 기록 구조에 부적합

## 결정

**sqflite** 를 선택한다.

## 이유

- 운동 기록은 세션-세트-종목의 관계형 구조 → SQL이 적합
- 오프라인 완전 동작 — 발표 데모 시 Wi-Fi 불필요
- Won't에서 클라우드 동기화 명시적 제외 → Firebase 불필요

## 변경 이력

- 2026-05-18: expo-sqlite 선택 (React Native 기준)
- 2026-06-01: sqflite로 변경 (Flutter 전환)
