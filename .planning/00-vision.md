# 비전 및 목표

> 작성: AI Agent 자동 생성 / 본인 검토 완료 (2026-05-18)

## 한 줄 주제

꾸준히 운동하고 싶지만 혼자선 계획이 흐트러지는 중급 운동인을 위해,
AI가 대화로 계획·기록·피드백을 한 번에 코칭해주는 React Native 모바일 앱

## 문제 정의

혼자 운동하는 중급자는 운동 방법을 아는 것과 꾸준히 실천하는 것 사이의 간극이 크다.
- 계획은 세우지만 며칠 지나면 흐트러짐
- 기록을 남겨도 분석하지 않으면 의미 없음
- PT 없이 스스로 루틴을 조정하기 어려움

## 솔루션

AI와의 텍스트 대화로 세 가지를 한 앱에서 해결한다.
1. **계획 생성**: 오늘 컨디션·목표·지난 기록을 반영한 맞춤 세트 제안
2. **기록 분석**: 세트/무게/횟수를 입력하면 성장률과 다음 목표 피드백
3. **루틴 조정**: 일정 변화를 말하면 주간 루틴을 자동으로 재배치

## 핵심 가치 제안

> "AI 퍼스널 트레이너를 주머니에"
> 대화 한 마디로 오늘 운동이 결정되고, 끝나면 기록이 분석된다.

## 목표

| 구분 | 내용 |

| 14주차 (마감) | Must 기능 전부 완성 + APK 빌드 가능 |
